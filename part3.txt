จากภาพ FUZZY Logic เป็นการระบุความเป็นสมาชิกด้วยความคลุมเคลือเช็น เป็น ค่อนข้าเป็น เป็นนิดหน่อย ไม่ค่อยเป็นนะ เป็นต้น ซึ่งในภาพจะมี2 input คือ service และ food และ output เป็น tip กราฟของแต่ละ inputและ output จะได้มาจากการสำรวจพฤติกรรมหรือจากผู้เชี่ยวชาญ
Fuzzy inferenceจะเป็นการรวมค่า output เพื่อนำมา defuzzyเพื่อหาข้อสรุปจากผลลัพธ์ทั้งหมด
จากภาพเงื่อนไขคือ if service is poor or food is rancid then tip = cheap โดยที่ serviceได้คะแนน3 fooodได้คะแนน8 จาก10(กำหนดเอง) ก็นำมาเทียบกับกราฟของ2 input ในเงื่อนไขแรก แล้วเอาผลลัพธ์ของ2 input มาหา or(Max)
เช่น สมมุติว่าservice มีความเป็นสมาชิกของ poor อยู่ 0.4 โดยเคื่อน3ไปตามแกนx แล้วตีเส้นขึ้นไปให้โดนกราฟเพื่อหาค่า yหรือmiu ทำแบบนี้กับทุกกราฟ foodจะเป็นสมาชิกของ rancid อยู่ 0 จากนั้นนำค่าที่มากที่สุดไป limit tip=cheap graph จะได้ tip1 ออกมา
จากนั้นทำแบบนี้กับอีก2เงื่อนไขที่เหลือ ถ้าไม่มี operation อะไรก็เอาค่าmiu ที่ได้มาlimitเลย เราจะได้tipออกมา3ค่า เอาทั้งสามมารวมกันแล้วทำกัน defuzzyด้วยการหจุดcentroid แล้วค่าแกนxที่ได้คือค่าตัวแทน ในรูปคือ16.7% จาก25%(กำหนดไว้ว่าtipมาค่าถึงเท่านี้)
