แขนของเราจะใช้เป็นแขนกลของ Arctos robot ที่ใช้closed loop stepper เป็นตัว actuator โดยที่มี eye on hand และกล้องอีก2ตัวมองที่ตัวคน โดยงานหลักในตอนนี้คือให้หุ่นสามารถควบคุมด้วยpipe และสามารถเข้าไปหยิบแก้วด้วยdepth camera

ตัว softwareจะมี2ฝั่งหลักๆคือฝั่งหุ่นที่จะควบคุม path planning, motion controlและระบุstateของหุ่น ฝั่ง UI จะคอยดูแลเรื่องกล้องและtask planning 
UI จะมีตัวเลือกTask ให้สามารถบันทึกค่าตำแหน่งปัจจุบันของหุ่นโดยเราสามารถสั่ง jogหุ่นด้วยกล้องจากการกำนดปลายแขน หรือ กดที่ padใน ui ก็ได้ สามารถกำหนดประเภทของการเคลื่อนที่ได้ว่าจะเป็น Task/joint space สามารถเปลี่ยนลำดับของตัวงานได้ด้วยว่าจะให้ทำอะไรก่อนอะไรหลัง
และจะมีตัวกล้องที่ดูตำแหน่งของ pipe skeleton ที่รู้ความลึกz จากการ merge2กล้องเข้าด้วยกัน คอยเช็คว่าตัวคนเข้าใกล้หุ่นเกินไปหรือไม่ เพื่อลดความเร็วหรือสั่งหยุดหุ่นชั่วคราว(pause) โดยที่ตัวUI จะส่ง/goto_position เป็นตำแหน่งของ joint แต่ละjoint,gripperกางเท่าไหร่,ความเร็วไปให้
เพื่อให้หุ่นสามารถวิ่งตามได้และถ้ากำหนดตำแหน่งจุดปลาย และบอกว่าให้เป็น Task/Joint space ตัวหุ่นจะมีการตรวจสอบว่าจะชนกับฐานหรือไม่  ถ้าชนจะมีการวิ่งเบี่ยงจากเส้นตรงการกระจัดเป็นรูปสามเหลี่ยมแทน มีการป้องกันการชนสำหรับการ jogถ้าแขนอยู่ในช่วงระยะที่กำหนดสั่งห้ามไปทันที
หุ่นด้วยกล้องจากการกำนดปลายแขน และหุ่นจะมีการส่ง state ไปบอกui ว่าตอนนี้ทำงานเสร็จแล้วหรือยัง
เพื่อให้ ui ตัดสินใจสำหรับการส่งคำสั่งต่อไป 

ระบบนี้จะสามารถเคลื่อนที่ได้หลากหลายรูปแบบทั้ง Task/Joint space มีตัวเลือกในการtrainแบบlearning by showing หุ่นที่หลากหลาย ทั้งjogผ่านแขน หรือUI มีระบบsafety ที่จะตรวจว่ามีคนอยู่ใกล้หุ่นยนต์มากเกินไปไหมสามารถปรับค่าระยะได้ใน uiด้วย
ทำให้หุ่นยนต์และคนมีความปลอดภัยมากยิ่งขึ้น และยังมีการป้องกันไม่ให้หุ่นเคลื่อนที่ไปชนฐานทั้งการกำหนดตำแหน่งวิ่งและการ jog จึงเป็นหุ่นที่ใช้งานได้ค่อนข้างหลากหลายสถานการณ์
